# 电商ERP系统 - HTML原型

这是一个电商ERP系统的HTML原型，展示了系统的主要界面和功能布局。

## 快速开始

直接用浏览器打开 `index.html` 文件即可查看原型。

## 演示账号

- **用户名**: admin

## 主要页面

- `index.html` - 登录页面
- `dashboard.html` - 系统仪表板
- `pages/users/user-list.html` - 用户管理
- `pages/products/product-list.html` - 商品管理
- `pages/orders/order-list.html` - 订单管理
- `pages/inventory/inventory-list.html` - 库存管理
- `pages/platforms/platform-list.html` - 平台管理
- `pages/logistics/logistics-list.html` - 物流管理

## 功能特性

- 响应式设计，支持桌面和移动端
- 模拟数据展示
- 基本的交互功能
- 现代化的UI设计

## 技术说明

- 纯HTML/CSS/JavaScript实现
- 使用Font Awesome图标
- 包含模拟数据和基本交互
- 无需服务器，直接打开HTML文件即可使用

## 注意事项

这只是一个静态原型，用于展示界面设计和用户体验。实际的业务逻辑需要在后端实现。
