## 系统介绍

### 系统功能概览

ERP系统是一套综合性的电商管理平台，主要功能包括：

- **订单管理**: 自动拉取和处理电商平台订单
- **商品管理**: 统一管理SKU信息和商品数据
- **库存管理**: 实时库存跟踪和预警
- **平台对接**: 支持沃尔玛等主流电商平台
- **物流管理**: 集成云途等物流服务商
- **多店铺管理**: 支持多个店铺统一管理
- **数据分析**: 提供业务数据统计和分析

### 系统架构

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   电商平台      │    │   ERP系统       │    │   物流服务商    │
│  (沃尔玛等)     │◄──►│                 │◄──►│  (云途等)       │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                              │
                              ▼
                       ┌─────────────────┐
                       │   管理后台      │
                       │  (用户界面)     │
                       └─────────────────┘
```

## 快速开始

### 1. 登录系统

1. 打开浏览器，访问系统地址：`https://erp.yourdomain.com`
2. 输入用户名和密码
3. 点击"登录"按钮

### 2. 系统首页

登录成功后，您将看到系统首页，包含：

- **仪表板**: 显示关键业务指标
- **快捷操作**: 常用功能的快速入口
- **通知中心**: 系统通知和提醒
- **导航菜单**: 各功能模块的入口

### 3. 基本操作

#### 导航菜单
- 点击左侧菜单项可以切换到不同功能模块
- 支持多级菜单展开和收起
- 当前页面在菜单中会高亮显示

#### 数据表格
- 支持排序、筛选、搜索功能
- 可以调整列宽和显示/隐藏列
- 支持批量操作和导出功能

#### 表单操作
- 必填字段标有红色星号(*)
- 支持实时验证和错误提示
- 可以保存草稿或直接提交

# 用户管理

### 1. 用户列表

**路径**: 系统管理 → 用户管理

**功能说明**: 查看和管理系统用户

#### 操作步骤
1. 点击左侧菜单"系统管理" → "用户管理"
2. 在用户列表中可以看到所有用户信息
3. 支持按用户名、邮箱、状态等条件搜索

#### 列表字段说明
- **用户名**: 登录系统使用的用户名
- **姓名**: 用户的真实姓名
- **邮箱**: 用户邮箱地址
- **角色**: 用户在系统中的角色
- **状态**: 用户账户状态（启用/禁用）
- **最后登录**: 用户最后一次登录时间

### 2. 添加用户

#### 操作步骤
1. 在用户列表页面点击"添加用户"按钮
2. 填写用户基本信息：
   - 用户名（必填，唯一）
   - 姓名（必填）
   - 邮箱（必填，唯一）
   - 手机号码
   - 初始密码（必填）
3. 选择用户角色
4. 设置用户状态
5. 点击"保存"按钮

#### 注意事项
- 用户名和邮箱必须唯一
- 初始密码建议设置为强密码
- 新用户首次登录需要修改密码

### 3. 角色权限管理

**路径**: 系统管理 → 角色管理

#### 预设角色
- **系统管理员**: 拥有所有权限
- **运营经理**: 订单、商品、库存管理权限
- **仓库管理员**: 库存、物流管理权限
- **客服人员**: 订单查看和基本操作权限

#### 权限说明
- **查看权限**: 可以查看相关数据
- **编辑权限**: 可以修改相关数据
- **删除权限**: 可以删除相关数据
- **导出权限**: 可以导出相关数据

## 商品管理

### 1. SKU管理

**路径**: 商品管理 → SKU管理

**功能说明**: 管理商品的基础信息和SKU数据

#### 添加SKU
1. 点击"添加SKU"按钮
2. 填写基本信息：
   - **SKU编码**: 唯一标识符（必填）
   - **商品名称**: 商品标题（必填）
   - **商品描述**: 详细描述
   - **分类**: 选择商品分类
   - **品牌**: 商品品牌
3. 填写价格信息：
   - **销售价格**: 对外销售价格
   - **成本价格**: 商品成本价格
   - **建议零售价**: 建议零售价格
4. 填写物理属性：
   - **重量**: 商品重量（克）
   - **尺寸**: 长×宽×高（厘米）
   - **颜色**: 商品颜色
   - **尺码**: 商品尺码
5. 上传商品图片
6. 点击"保存"按钮

#### 批量导入SKU
1. 点击"批量导入"按钮
2. 下载导入模板
3. 按照模板格式填写商品信息
4. 上传填写好的Excel文件
5. 系统会验证数据并显示导入结果
6. 确认无误后点击"确认导入"

#### 导入模板格式
| SKU编码 | 商品名称 | 分类 | 品牌 | 销售价格 | 成本价格 | 重量 | 长度 | 宽度 | 高度 |
|---------|----------|------|------|----------|----------|------|------|------|------|
| SKU001  | 示例商品 | 电子产品 | 品牌A | 99.99 | 50.00 | 500 | 10 | 8 | 2 |

### 2. 商品分类管理

**路径**: 商品管理 → 分类管理

#### 添加分类
1. 点击"添加分类"按钮
2. 填写分类信息：
   - **分类名称**: 分类的名称
   - **父级分类**: 选择上级分类（可选）
   - **分类描述**: 分类说明
   - **排序**: 显示顺序
3. 点击"保存"按钮

#### 分类层级结构
```
电子产品
├── 手机数码
│   ├── 智能手机
│   └── 平板电脑
└── 电脑办公
    ├── 笔记本电脑
    └── 台式电脑
```

## 订单管理

### 1. 订单列表

**路径**: 订单管理 → 订单列表

**功能说明**: 查看和管理所有订单信息

#### 订单状态说明
- **待处理**: 新拉取的订单，等待处理
- **已确认**: 订单已确认，等待发货
- **已发货**: 订单已发货，等待收货
- **已完成**: 订单已完成
- **已取消**: 订单已取消

#### 筛选和搜索
- **按状态筛选**: 选择特定订单状态
- **按时间筛选**: 选择订单日期范围
- **按平台筛选**: 选择特定电商平台
- **按店铺筛选**: 选择特定店铺
- **关键词搜索**: 按订单号、客户名称等搜索

### 2. 订单详情

#### 查看订单详情
1. 在订单列表中点击订单号
2. 查看订单详细信息：
   - **基本信息**: 订单号、下单时间、订单状态
   - **客户信息**: 客户姓名、联系方式、收货地址
   - **商品信息**: 商品列表、数量、价格
   - **支付信息**: 支付方式、支付状态、金额
   - **物流信息**: 物流公司、运单号、物流状态

#### 订单操作
- **确认订单**: 确认订单信息无误
- **修改地址**: 修改收货地址（限特定状态）
- **取消订单**: 取消订单（限特定状态）
- **发货**: 生成物流单并发货
- **添加备注**: 添加订单处理备注

### 3. 订单处理流程

#### 标准处理流程
```
订单拉取 → 订单确认 → 库存扣减 → 生成物流单 → 订单发货 → 状态同步
```

#### 详细操作步骤
1. **订单拉取**
   - 系统自动从电商平台拉取新订单
   - 订单状态为"待处理"

2. **订单确认**
   - 检查订单信息是否正确
   - 确认商品库存是否充足
   - 点击"确认订单"按钮

3. **库存扣减**
   - 系统自动扣减相应商品库存
   - 如库存不足会提示并暂停处理

4. **生成物流单**
   - 选择物流服务商
   - 系统自动生成物流单
   - 获取运单号

5. **订单发货**
   - 打印物流单
   - 包装商品并发货
   - 更新订单状态为"已发货"

6. **状态同步**
   - 系统自动同步状态到电商平台
   - 发送发货通知给客户

## 常见问题

### 1. 登录问题

**Q: 忘记密码怎么办？**
A: 在登录页面点击"忘记密码"，输入用户名或邮箱，系统会发送重置密码的邮件。

**Q: 登录后页面空白？**
A: 可能是浏览器兼容性问题，建议使用Chrome、Firefox等现代浏览器。

**Q: 提示账户被锁定？**
A: 连续输错密码会导致账户锁定，请联系管理员解锁或等待自动解锁。

### 2. 订单问题

**Q: 为什么订单没有自动拉取？**
A: 检查以下几点：
- 店铺API配置是否正确
- 网络连接是否正常
- 平台API是否有调用限制
- 同步任务是否正常运行

**Q: 订单状态同步失败怎么办？**
A: 
1. 检查平台API连接状态
2. 查看错误日志了解具体原因
3. 手动重新同步订单状态
4. 如问题持续，联系技术支持
